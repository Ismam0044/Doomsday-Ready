# Movie posters

Poster files are served from this folder and matched to movies by these names:

- `iron-man.jpg`
- `captain-america-the-first-avenger.jpg`
- `the-avengers.jpg`
- `captain-america-civil-war.jpg`
- `thor-ragnarok.jpg`
- `avengers-infinity-war.jpg`
- `avengers-endgame.jpg`
- `avengers-doomsday.jpg`

Movie cards preserve each image's proportions, so portrait posters and wide
backdrops stay intact. If an image is missing, its card shows a designed title
treatment instead of borrowing another movie's artwork.
